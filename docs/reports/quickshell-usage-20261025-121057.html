Where to investigate next

  1. Pause nonessential widget animations and rendering selectively. Keep locking, notifications and essential controls responsive.
  2. Reduce repeated child-process polling. About 7.9% of one core was charged to reaped child work across phase-start snapshots; the stable Home Assistant daemon was about 0.03%. Individual plugins were not isolated.
  3. Unload resources if memory is the goal. Pausing timers or using SIGSTOP does not free RAM/VRAM. Shared allocations are not guaranteed reclaimable.
  4. Validate in a real fullscreen game. Compare identical scenes and frame-time logs before claiming any gaming improvement.
What this does—and does not—prove

All sampled checks were unlocked with no screensaver, and desktop state was restored. This is a live desktop baseline, not a fullscreen game benchmark or a before/after widget-pause test. Occlusion, VRR/frame scheduling, content changes and sampling overhead can affect results.

The earlier uncertain-lock run and aborted restart run are excluded. No widgets, polling settings or shell functionality were changed.
